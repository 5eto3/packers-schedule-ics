# Packers Schedule ICS Generator

NFL（Green Bay Packers）のスケジュールを取得し、GoogleカレンダーやiOSカレンダーで読み込めるICSファイルを生成するPythonスクリプトです。

## 特徴

- **NFL公式系データ**: `nflreadpy` ライブラリを使用して信頼性の高いスケジュールを取得。
- **JST変換**: 米国東部時間 (ET) を自動的に日本標準時 (JST) へ変換。
- **カレンダー対応**: Google / iOS カレンダーへインポート可能な ICS ファイルを出力。
- **複数シーズンの統合対応**: 2024-2025 のように範囲指定して複数を 1 つのファイルにまとめられます。
- **生成物の整理**: 生成されたファイルは `dist/` ディレクトリに自動的にまとめられます。

## セットアップ

### 依存関係のインストール

このプロジェクトでは Python 3.10 以上が必要です。

```bash
# ライブラリのインストール例
pip install nflreadpy pandas pytz icalendar polars
```

## 使い方

対象のシーズン（年）またはシーズンの範囲を指定してスクリプトを実行します。

### 単一シーズンの場合

```bash
python3 make_packers_calendar.py 2025
```

### 複数シーズンの範囲指定（推奨）

2024年から2025年のように、複数のシーズンを1つのカレンダーにまとめたい場合：

```bash
python3 make_packers_calendar.py 2024-2025
```

### 出力ファイル

実行後、`dist/` ディレクトリに以下のファイルが生成されます：

- `dist/packers_2024-2025.ics`: カレンダーアプリにインポートして使用。
- `dist/packers_2024-2025.csv`: 生成内容を確認するための CSV ファイル。

## ソース管理 (Git) について

- **スクリプト本体 (`make_packers_calendar.py`)**: Gitでの管理対象です。
- **生成物 (`dist/`, `*.ics`, `*.csv`)**: Gitの管理対象外です。環境ごとに生成して利用してください。

## 注意事項
- 試合開始時刻が未確定（TBD）の場合はデータに含まれないか、空になる可能性があります。スケジュール確定後に再実行してください。
